# Review: docs/api.md (2186 lines) -- reviewer "api"

## Summary
The Core section (EventType..traced_step, spans, ReplayEngine) is mostly accurate and the 4.2 span additions are well documented; the core examples run. But api.md is badly incomplete and has several wrong/misleading items: a Claude Code example that crashes (`Chain.load("str")`), a `run_dashboard(reload=True)` example that exits with code 3, a wrong `run_dashboard` host default (doc 0.0.0.0, code 127.0.0.1), and `auto_instrument()` described as instrumenting frameworks when it only creates a global session. Whole public surface areas have zero coverage: streaming, metrics, evaluation, redaction (on by default!), schema, DSPy and LlamaIndex integrations, base tracer classes, 8 of 13 CLI commands, and ~20 of 25 dashboard endpoints. The TOC has a broken anchor and omits 4 sections; there is no install/prerequisites section.

Verification method: read source; ran core examples in /tmp/.../docs-audit/api/ with the repo venv; ran dashboard via FastAPI TestClient; ran `lctl --help` and every subcommand. Framework integrations (langchain, crewai, autogen, openai-agents, pydantic-ai, semantic-kernel) verified by source reading only.

## Structural recommendations
1. Split into `docs/api/` pages (core, session, integrations/<framework>, dashboard-http, streaming, metrics-evaluation, cli) with api.md as an index; integrations already have tutorials, so keep api.md entries to signature + link.
2. Add Installation and "package version vs trace format version" boxes at top; make the TOC cover every H2.
3. Give every integration the same H3 template (Install extra, Import, Constructor, Captured events, Methods, Example) and unique headings (`AutoGen: trace_agent`) to avoid anchor collisions.
4. Add a Security & configuration subsection for the dashboard (host default, API keys, env vars, CORS) before the endpoint list; add a single endpoint reference table.
5. Generate the CLI and endpoint tables from `lctl --help` / FastAPI `app.routes` (or an OpenAPI dump) to avoid drift; add a doctest/CI check that runs the core snippets (items 1, 2, 12 would have been caught).
