# tutorials-a findings

Files: docs/tutorials/{claude-code,langchain,openai-agents,autogen}-tutorial.md (all paths under /home/kim/projects/llm-context-transfer)

Method: read all four docs + integrations/{claude_code,langchain,openai_agents,autogen,base}.py + `lctl claude` in cli/main.py; ran every `lctl claude ...` command and every claude_code.py API example; ran generated hooks with JSON on stdin; and (outside the repo venv) built scratch venvs under scratchpad/docs-audit/tutorials-a/{fw,ag2env} with REAL frameworks (openai-agents 0.23.1, langchain 1.4.5 / langchain-core 1.6.10 / langchain-community 0.4.2, pyautogen 0.10.0 + autogen-agentchat 0.7.5, ag2 1.1.2 and ag2 0.14.0) and drove the tutorial examples against them with fake models (no network). I also ran a live `claude -p` probe (Claude Code 2.1.299, haiku, one subagent call, budget-capped) with a stdin-dump hook to capture the real hook payloads. Nothing in the repo was modified.

## Summary
- Claude Code tutorial: the core feature is broken on current Claude Code. The subagent tool is now named `Agent` (live probe, 2.1.299); generated hooks only match `tool_name == 'Task'`, so no step_start/step_end is ever recorded for subagents. `Stop.sh` also crashes on every run (bash quoting bug), never deletes the state file, and Stop fires per turn, not at session end. `lctl claude init --force` wipes all other keys in `.claude/settings.json`, and plain `init` replaces every existing hook. All shown CLI outputs (`validate`, `status`, `stats`, `trace`, `bottleneck`) are invented and do not match real output; `replay --to-checkpoint` does not exist; `claude config get hooks` is not a command.
- OpenAI Agents tutorial: the headline pattern `Runner.run(..., run_config=tracer.run_config)` raises `TypeError: Unknown run_config settings: hooks` on openai-agents 0.23.1 (hooks must be passed as `hooks=`). Even with hooks=, any real tool call crashes (`LCTLRunHooks.on_tool_start() missing 1 required positional argument: 'input_data'`, code bug, SDK passes 3 args). `handoffs=["sales","support"]` strings are silently ignored by the SDK.
- AutoGen tutorial: `pip install lctl[autogen]` (pyautogen 0.10.0) or `pip install autogen-agentchat` puts LCTL in "modern" mode where every wrapper class (`LCTLConversableAgent`, `LCTLGroupChatManager`) raises "AutoGen is not installed", `attach()` is a no-op, and `from autogen import ...` fails. `pip install ag2` now installs 1.1.2 which has neither `autogen` nor `ConversableAgent` (tutorial only works with `ag2<1`, verified on 0.14.0, which also needs `ag2[openai]`). "Share chain_id to combine traces" is false (separate sessions).
- LangChain tutorial: Step 1 import (`langchain_available` from `lctl.integrations.langchain`) raises ImportError; `Chain.load("file")` with a str crashes (also in openai/autogen); Example 4 (bind_tools) cannot produce tool events. Core handler/LCTLChain/trace_chain examples do work on langchain 1.x.
- All four share boilerplate: stale "v4.0", "Python 3.9+" (needs >=3.11), `pip install lctl` (not on PyPI), invented CLI outputs, dead `../cli/README.md` link, and a section named "How to View Traces in the Dashboard" that is CLI-only.
