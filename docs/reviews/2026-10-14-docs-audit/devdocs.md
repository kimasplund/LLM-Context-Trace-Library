# devdocs findings: CLAUDE.md, vscode-lctl/README.md, vscode-lctl/MANUAL.md

## Summary
CLAUDE.md is mostly accurate and its core examples run (session/replay/span/Chain.load/CLI/file-format snippets all verified), but its Integration Guide template does not match how the real integrations are written (6 ruff errors, undefined `trace_agent`, `IntegrationNotAvailableError` used by none), Pattern 5 tells agents to hand-roll `_truncate` instead of using `base.truncate`, and ~40% of the 662 lines is duplicated or copy-of-code bloat. The VS Code docs are in much worse shape: MANUAL.md has a non-working build recipe, wrong Python/version/file-format facts, a non-existent "Replay Chain" button and "interactive terminal" replay; README documents 3 settings that no code reads, and 4 palette commands that error when run from the palette. A real extension bug also affects the docs' token/cost claims (extension reads `tokens_in/out`, the library writes `tokens.{input,output}`, so tokens/cost are always 0).

## Structural recommendations
1. CLAUDE.md is loaded into every AI context; at 662 lines it is ~40% duplication. Cut: Key Fixtures + Writing Tests code (lines 364-412, ~50 lines; drifts from tests/conftest.py; just say "see tests/conftest.py"), Option A/B full templates (422-499, ~80 lines; replace with pointers to pydantic_ai.py / langchain.py and the TracerDelegate docstring in base.py:134-150), "Quick Commands" dev block (524-530) duplicates Setup/Tests/Lint, Directory Structure partially duplicates Architecture, File Formats (550-592) duplicates README/spec/docs/api.md (keep a 1-line pointer), Confidence thresholds/Facts decay (spec content, unimplemented), Core Philosophy marketing quote, Common Tasks CLI/dashboard snippets. Target ~300-350 lines. Keep: architecture, patterns that bite (graceful degradation, session methods only, use `base.truncate`), commands, gotchas.
2. Add a short "Gotchas" section (see #33, #35) and correct the integration convention (#22-#24); keep examples tested (consider a doctest/pytest that extracts and runs the CLAUDE.md python fences, since ruff already reformats the Markdown).
3. Collapse vscode-lctl docs: README = what/install/quickstart/commands(with where-to-run)/settings(only working)/shortcuts/troubleshooting; MANUAL = dashboard walkthrough; link them to each other. Move build-from-source into README or a CONTRIBUTING-style section aligned with CI. Fix the code-level mismatches first (#4, #6, #7) or the docs will keep describing behavior that does not exist.
