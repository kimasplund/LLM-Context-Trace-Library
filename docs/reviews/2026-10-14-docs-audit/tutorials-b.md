# tutorials-b findings

Scope: docs/tutorials/{crewai,llamaindex,dspy,pydantic-ai,semantic-kernel}-tutorial.md and all of examples/ (9 .py + sample-chain.lctl.json).
Repo not modified. Scratch work in `.../docs-audit/tutorials-b/` (run/ scripts, v-* venvs).

Verification method: I did NOT stop at source reading. I built scratch venvs (outside the repo venv) with the real frameworks and ran the tutorial code with fake/test models and `PYTHONPATH=/home/kim/projects/llm-context-transfer`:
dspy 3.4.1 (DummyLM), llama-index 0.14.25 / llama-index-core 0.12.52 (MockLLM), crewai 1.15.28 (fake BaseLLM), pydantic-ai 2.56.0 and 1.107.7 (TestModel/FunctionModel), semantic-kernel 1.45.0 (fake chat service), openai-agents 0.23.1. Items I could not run are marked "unverified".

## Summary

The five tutorials are in poor shape: almost every tutorial has a "complete working example" that fails against the current framework or against LCTL itself. Worst: (1) the whole LlamaIndex integration crashes against real llama-index (missing `super().__init__`, `trace_map` setter), so the tutorial and `llamaindex_example.py` cannot work; (2) `TracedAgent.run()` for PydanticAI raises `TypeError` on pydantic-ai 2.x (`result.usage()` is now a property) and tutorial/example use removed APIs (`result.data`, `result_type`, `from pydantic_ai import tool`); (3) the Semantic Kernel tutorial and example use methods that do not exist (`@kernel.function`, `kernel.import_plugin_from_object`, `kernel.create_function_from_prompt`); (4) every sample CLI output in all five tutorials is invented (real `lctl trace/stats/bottleneck` print different formats), and the DSPy tutorial claims nested predictor, tool and optimizer events that the wrapper never emits. In examples/, `langchain_example.py` dies on import, 3 of 4 `*_agent.py` scripts crash even with the framework installed, and `crewai_example.py` exports an empty trace. None of the tutorials or examples is linked from README.md (only claude-code-tutorial.md is). All cross-links to `../cli/README.md` are dead.
